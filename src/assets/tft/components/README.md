# TFT component icons

Original, unmodified Riot Games artwork downloaded from Riot's Data Dragon CDN.
Artwork belongs to Riot Games; it is not original broccosite artwork.

- Downloaded: 2026-09-12
- Data Dragon version: `16.18.1`
- Documentation: https://developer.riotgames.com/docs/tft#data-dragon
- Manifest: https://ddragon.leagueoflegends.com/cdn/16.18.1/data/en_US/tft-item.json
- Image URL: `https://ddragon.leagueoflegends.com/cdn/16.18.1/img/tft-item/{riotId}.png`

The `riotId`, display name, and local image import for each icon are in
`src/components/tft/components.ts`. Use the display name as alt text when the
icon conveys information; use empty alt text when an adjacent label repeats it.

Includes the eight standard components, plus Spatula and Frying Pan.
Only artwork and names are imported; there are no patch-specific stats or recipes.
